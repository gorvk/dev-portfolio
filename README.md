# Developer Portfolio - https://gorvk.netlify.app

## Reusable personal website for developers

#### follow below steps to change your data in the site.
- convert env.example to .env and fill respective values
- change values in models/siteData.ts with yours.

#### follow below steps to run the project.
- ```npm install```
- ```npm start```
